# Lesson 标题

## Lesson

用一句话说明未来 Agent 必须记住的失败模式或保护原则。

## Trigger

说明这次失败、回归、验证缺口或流程问题是在什么场景下暴露的。

## Root Cause

区分触发条件和根因。根因应解释为什么这个问题在系统中可能发生。

## Protection

- 写下已经加入或必须加入的测试、门禁、脚本、CI、权限约束或流程规则。
- 不要只写“以后小心”。

## Recurrence Check

说明这个失败模式是否可能复发，以及未来 Agent 如何识别同类风险。

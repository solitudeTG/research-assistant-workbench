# F018.7 Evidence Curation Contract Plan

## Goal

Add a deterministic evidence curation boundary so Plan-Execute downstream audit and document composition operate on accepted evidence, not raw retrieval candidates.

## Execution Strategy

- Use TDD: write failing focused tests before production code.
- Keep the implementation small and local to F018 orchestration.
- Prefer contract records and a deterministic service over another visible subagent.
- Preserve the existing UI-visible multi-agent story: three subagents, serial execution, truthful trace events.

## Tasks

- [x] Add contract tests for `CuratedEvidenceItem`, `CuratedEvidenceSet`, and `EvidenceCurator`.
- [x] Implement `EvidenceCurator` with deterministic topic relevance and garbage-fragment rejection.
- [x] Add `ResearchPacket.withEvidence(...)` helper so the loop can pass a curated packet downstream without changing every constructor call.
- [x] Integrate curation into `MultiAgentPlanExecuteLoop` immediately after `Deep Research Agent` completes and before `Evidence Audit Agent`.
- [x] Add a Plan-Execute regression test proving audit/composer receive curated evidence only.
- [x] Update Evidence and Feature docs after verification.
